# Voxel Seoul — Ezra Song's Interactive 3D Portfolio

Drive a poro through a handcrafted miniature voxel Seoul. Each building in
the city is a portfolio project — walk up to its entrance and press **E** to
step inside. Built with Three.js, TypeScript, and cannon-es.

**Live site:** https://ezrasong.github.io

## Inspiration & attribution

The *interaction model* — a physics-driven character exploring a diorama
world where locations open portfolio content — is inspired by
[Bruno Simon's Folio 2019](https://github.com/brunosimon/folio-2019)
(MIT License, © 2019 Bruno Simon). No code, models, textures, audio,
branding, or personal content from that project is included here; the
reference was studied for architectural ideas (application orchestration,
fixed-step physics, action-map input, interaction zones), and everything in
this repository — the voxel Seoul environment, the building generator, the
UI, and all systems code — was written from scratch for this portfolio.

The player character (`public/models/poro.glb`) is a fan-made Poro model
supplied by the site owner; the Poro character originates from League of
Legends (Riot Games). Replace it if you redistribute this project.

## Tech stack

- [Vite](https://vitejs.dev) + TypeScript (strict)
- [Three.js](https://threejs.org) — rendering, one merged geometry per structure
- [cannon-es](https://github.com/pmndrs/cannon-es) — physics (static boxes + one dynamic sphere)
- [GSAP](https://gsap.com) — building-entry camera cinematics
- Web Audio API — all sound is synthesized, no audio files
- Plain HTML/CSS overlays — panels, menu, HUD (no UI framework)

```sh
npm install
```

## Controls

| Input | Action |
| --- | --- |
| `W` / `↑` | move forward |
| `S` / `↓` | reverse |
| `A` `D` / `←` `→` | steer |
| `E` / `Space` | enter a building (near its door) |
| `M` | city directory (keyboard-friendly navigation without walking) |
| `R` | reset to the plaza |
| `Esc` | close panel / directory |

On touch devices a virtual joystick and an `E` button appear automatically.

## Editing portfolio content

Everything a visitor reads lives in `src/config/`:

- **Add or edit a project:** edit `src/config/projects.ts`. Each entry
  carries its copy (title, description, role, tech, challenge, outcome,
  links) *and* its building (type, district, position, footprint, facing,
  accent color). Change `buildingType` to restyle the architecture:
  `arcade`, `creative-studio`, `tech-lab`, `glass-store`, `server-facility`,
  `office-tower`, `workshop`, `hanok-house`.
- **Personal info:** `src/config/profile.ts` (about paragraphs, skills,
  experience, education, GitHub/LinkedIn/email/résumé links).
- **Positioning a building:** `position` is the footprint center in world
  units; `facing` picks which side the door is on (`north` = towards
  Namsan/−Z, `south` = towards the river/+Z). The entrance trigger and
  camera approach are derived automatically. Keep centers ≥ ~12 units apart.

## Replacing the player model

Drop any GLB at `public/models/poro.glb`. The loader normalizes scale
(`targetHeight`), grounds the feet, and recenters automatically. Tune
`src/config/player.ts`:

- `modelYaw` if the model faces the wrong way
- `targetHeight`, `bodyRadius`, `groundOffset` for sizing
- `clips` to map your model's animation names (idle/run/interact/greeting);
  models without animations still work — procedural lean/bounce/squash
  covers movement.

## Performance notes

- Every structure is merged into at most two draw calls (lit + emissive).
- Trees, streetlights are `InstancedMesh`; background city blocks merge
  into a single mesh per batch; the whole ground is one painted canvas.
- Quality presets (low/medium/high) cap device pixel ratio and shadow-map
  size; the setting persists and defaults to low on coarse-pointer devices.
- Physics and world updates pause while a panel is open.

## Accessibility

- **M** opens a conventional keyboard-navigable directory that opens every
  project/place panel without 3D traversal (also used as the no-WebGL
  fallback).
- Panels are focus-trapped dialogs; focus returns on close; `Esc` closes.
- `prefers-reduced-motion` damps camera swoop, bounce/lean, and shortens
  cinematics.
- Sound is off by default; the toggle persists.
- External links use `rel="noopener noreferrer"`.
