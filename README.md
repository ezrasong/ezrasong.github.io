# ezrasong.github.io

## Audio

- `assets/audio/chill-chip.wav` — custom-generated calming chiptune loop that powers the in-scene soundtrack and audio-reactive visuals.

## Characters

- Drop your Quagsire model at `assets/models/quagsire.glb`. The loader in `main.js` animates it through the scene and ties its swim cycle to the audio-reactive system so it can also collide with the bubbles.
